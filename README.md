# JAX Addition Transformer

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/marcoharuni/jax-addition-transformer/blob/main/notebooks/01_build_train_exact_10m.ipynb)

A decoder-only arithmetic language model, written from scratch with JAX primitives and Flax NNX, whose default architecture has exactly 10,000,000 trainable parameters.

The repository contains the complete experiment. Numerical results are generated by running the notebook or CLI. No unverified metrics are included.

## Verified scope

The model learns supervised fixed-width additions with operands from 0 through 999. It has no calculator call in generation, no pretrained components, and is not a general chatbot. CPU unit tests verify the implementation; the full 5,000-step experiment is intended for one free Colab NVIDIA T4.

“From scratch” means embeddings, projections, normalization, positional encoding, attention, feed-forward networks, masking, loss, and greedy decoding are expressed directly with `jax.numpy`, `jax.lax`, and `jax.nn`. NNX supplies module structure, `Param` ownership, RNG streams, and functional graph/state boundaries. None of the core built-in neural-network layers are used.

## Task representation

Every record has 16 characters:

```text
123 + 456 = 9750
```

Operands are three-digit, zero-padded strings. The normal four-digit answer `0579` is reversed to `9750`. Least-significant-digit-first generation lets an autoregressive model encounter a column’s input digits and incoming carry before predicting that column. The 15-token input is the record without its final character, and targets are shifted one place. Only target indices 11, 12, 13, and 14 contribute to loss.

The vocabulary is exactly `0`–`9`, space, `+`, and `=`, mapped to IDs 0–12. There is no padding token. Greedy decoding uses zeros only as initial values in a fixed future buffer; causal masking prevents those locations from influencing an earlier prediction, so token ID 0 retains its ordinary digit meaning.

## Default architecture

| Setting | Value |
|---|---:|
| Decoder blocks | 5 |
| Model width | 320 |
| Query heads × head width | 5 × 64 |
| FFN width | 2,480 |
| Normalization | Pre-LayerNorm |
| Activation | GELU |
| Positions | learned absolute, length 15 |
| Token/output weights | tied |
| Linear biases / dropout | disabled / 0 |
| Parameter storage | float32 |
| T4 matrix inputs | float16 with requested float32 accumulation |
| Norm, attention softmax, logits, loss | float32 |

Exact derivation:

```text
attention per block     4 × 320 × 320                   =   409,600
FFN per block           2 × 320 × 2,480                 = 1,587,200
two LayerNorms          2 × (320 scale + 320 bias)      =     1,280
five blocks             5 × 1,998,080                   = 9,990,400
tied token embedding    13 × 320                        =     4,160
position embedding      15 × 320                        =     4,800
final LayerNorm         320 scale + 320 bias            =       640
total                                                       10,000,000
```

`jat-inspect` checks this derivation against the actual NNX parameter tree and fails on disagreement. There is no separate output matrix.

## Dataset and split

All 1,000,000 ordered pairs use `pair_id = 1000*a + b`. Seed 42 creates disjoint 200,000/20,000/780,000 train/validation/unseen-test partitions, stratified by both operand lengths and three carry bits. Carry strings are ordered units, tens, hundreds from left to right: `100` means a units carry only. Largest-remainder allocation gives exact totals deterministically. Metadata records the seed, sizes, algorithm, and SHA-256 fingerprint; it does not store three enormous text files.

Tokenization is vectorized. A cached complete token array would occupy 64 MB as int32 (1,000,000 × 16 × 4 bytes); normal operation materializes requested batches. Training draws half a batch uniformly from training IDs and half by choosing a non-empty stratum uniformly, with explicit checkpointed NumPy Generator state.

## Objective and optimization

Training uses answer-only autoregressive cross-entropy. AdamW warms linearly from 0 to 1e-3 for 100 steps, then applies cosine decay to 1e-4 through step 5,000. Gradients are checked for finiteness and clipped to global norm 1.0. Weight decay 0.1 applies only to attention and FFN matrix kernels—not normalization, embeddings, positions, or biases.

Teacher-forced token accuracy is diagnostic. An expression is solved only when fixed-buffer greedy generation produces all answer digits correctly. Validation, unseen-test, and exhaustive results remain distinct; failures are written without rounding an imperfect score to 100%.

## Experiment knobs

`ModelConfig` implements LayerNorm/RMSNorm, learned positions/RoPE, GELU/ReLU/squared-ReLU/SwiGLU/GEGLU, and MHA/GQA/MQA. Dimensions, bias, weight tying, dtypes, epsilon, RoPE base, and initialization scale are configurable. `OptimizerConfig` implements AdamW, Adam, and momentum SGD. `TaskConfig` derives sequence lengths from `max_digits`. Only the frozen default is asserted to have 10,000,000 parameters; alternatives report their actual count.

## Repository map

Canonical code is under `src/jax_addition_transformer/`; the frozen experiment is `configs/exact_10m_t4.json`; the complete Colab is under `notebooks/`; design equations are in `docs/design.md`; notebook construction and publication checks are in `scripts/`; CPU checks are in `tests/`; real outputs go under ignored `runs/<run_id>/` directories.

## Reproducibility and results policy

JAX kernels and accelerator libraries can introduce platform-dependent floating-point behavior even with identical seeds. The lockfile records tested Python dependencies; environment artifacts record devices, backend, versions, commit, and configuration hash. Checkpoints reject incompatible configurations and include optimizer, step, sampler state, best result, and history.

No checkpoint, runtime, curve, or accuracy is committed without a real run. A perfect-addition claim requires zero unseen-test failures, zero exhaustive failures, and 100% in every reported slice.
